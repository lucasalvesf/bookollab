# Decisões (ADRs)

Registro curto de decisões técnicas e estruturais relevantes. Um arquivo por decisão: `NNNN-titulo-em-kebab-case.md` (ex.: `0001-escolha-da-stack.md`).

## Modelo

```markdown
# NNNN — Título

- Status: proposta | aceita | substituída por NNNN
- Data: AAAA-MM-DD

## Contexto
Qual problema ou necessidade levou a esta decisão.

## Decisão
O que foi decidido.

## Consequências
O que muda, ganhos, custos e riscos.
```
