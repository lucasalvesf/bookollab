# docs-aux

Material de **apoio** ao desenvolvimento do Bookollab: guias de ferramentas, referências, checklists e anotações de trabalho.

Não é documentação oficial do produto. Regras de negócio e decisões ficam em `docs/`. Se algo daqui virar decisão, mova para lá.

## Conteúdo
- [`ambiente-de-desenvolvimento.md`](ambiente-de-desenvolvimento.md): preparar um computador novo (programas, repositório, subir o projeto, Claude Code, Figma).
- [`claude/CLAUDE-global.md`](claude/CLAUDE-global.md): cópia das regras pessoais globais do Claude Code (vão em `C:\Users\<você>\.claude\CLAUDE.md`).
- [`claude-code-skills.md`](claude-code-skills.md): skills e agentes do Claude Code e como cada um ajuda no projeto.
