# CLAUDE.md — Código (src/)

Regras que valem só para o código do sistema. Continuam valendo as regras gerais do `CLAUDE.md` da raiz.

## Escopo
Tudo que é código do produto Bookollab vive aqui. Esta pasta é autocontida: não importa, executa nem depende de arquivos fora de `src/`.

## Layout planejado
- `apps/web/`: frontend web
- `apps/mobile/`: app mobile
- `backend/`: API

As pastas serão criadas quando a stack for decidida.

## Stack
Em definição. Quando decidida, será registrada em `docs/decisoes/` e resumida aqui (linguagens, frameworks, banco, comandos de build/teste/lint).

## Convenções de código
A definir junto com a stack. Até lá, código, identificadores e mensagens de commit sempre em inglês.
